# Тестовое задание для GREEN-API

Пользовательский интерфейс для отправки и получения текстовых сообщений в WhatsApp через GREEN-API.

## Суть реализации

В проекте реализованы:

- авторизация через данные инстанса GREEN-API (`idInstance`, `apiTokenInstance`);
- проверка состояния инстанса перед началом работы;
- создание нового чата по номеру телефона с проверкой наличия WhatsApp-аккаунта;
- отправка текстовых сообщений через API-метод `SendMessage`;
- получение входящих сообщений через `ReceiveNotification`;
- отображение статуса получения сообщений и уведомлений;
- обработка ошибок API и состояний загрузки.

Получение входящих сообщений реализовано отдельно от основной логики приложения через кастомный React Hook. Hook выполняет периодический опрос очереди уведомлений GREEN-API и преобразует полученные данные API в формат, используемый интерфейсом приложения.

## Запуск проекта локально

1. Клонируйте репозиторий или скачайте архив проекта.
2. Перейдите в директорию проекта:

```bash
cd "название-папки"
 
    Важные моменты при запуске
    Для корректной работы проекта необходимо иметь подключённый и авторизованный инстанс GREEN-API.
    Настройка GREEN-API
    1. Зарегистрируйтесь в GREEN-API.
    2. Перейдите в GREEN-API Console.
    3. Создайте новый инстанс через кнопку «Создать WhatsApp».
    4. Выберите подходящий тариф.
    5. Завершите подключение WhatsApp согласно инструкции сервиса.
    6. После авторизации инстанса получите idInstance и apiTokenInstance.
    Настройка уведомлений
    В настройках инстанса необходимо включить получение уведомлений:
    - Получать уведомления о входящих сообщениях и файлах — Да;
    - Получать уведомления о сообщениях, отправленных с телефона — Да;
    - Получать уведомления о сообщениях, отправленных с API — Да.
    После создания и авторизации инстанса введите полученные данные (idInstance, apiTokenInstance и API URL) в окне авторизации приложения.
